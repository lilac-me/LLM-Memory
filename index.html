Offload · 保存到 DDR

前向结束后搬出选定的激活，反向需要时搬回；计入 DDR 容量、带宽和恢复缓冲。

重计算 · 反向重新生成

input 按 BF16 hidden states 计：seq_length × micro_batch_size × hidden_size × 2 bytes。完全重计算覆盖 embedding 输出之后的所有层及 LM head；初始 input 只计一次。逐项模式仍按计算单位额外保留边界输入。额外 FLOPs / 耗时、RNG 和路由状态暂未细化。Megatron 重计算配置说明；本页整段峰值按保存重放中间量的方式估算。

所有激活项 · Offload再展开模块单独调整；百分比按钮不自动开启开关
所有激活项 · 重计算两种策略分配不同的激活份额，避免重复扣减

激活是每个 rank 的本地 micro batch，不除以 world size。保存张量包含 FP32 moe_gating logits（seq_length × micro_batch_size × n_routed_experts × 4 bytes × num_moe_layers）；当前统计不包含完整 attention scores 和 latent up 输出；切换模型后按配置维度重新计算。

公式直接使用配置字段名，例如 seq_length × micro_batch_size × q_lora_rank；当前值可在左侧“模型结构与维度”中查看。

FLOPs 与 MFU

按下方逐项公式汇总
MFU = 训练 FLOPs / (实测 step 秒数 × world_size × 每卡峰值 FLOPS)
训练 FLOPs ≈ 前向 FLOPs × 训练倍数
每 step 全局 token 数 = seq_length × global_batch_size（手动填写）

调度、分片与生命周期

  • 共享专家、router、latent down/up 属于非路由专家参数，按 world_size 分片；仅 routed experts 按 EP 再 EP-FSDP 分片。无 tied embedding，所有专家均分配状态，top-K 只影响激活与计算。
  • 默认每个 micro batch 顺序执行完整前向和反向；梯度累积不叠加多份完整激活。MLA / KDA 或 CSA / HCA 按层数均匀穿插，Dense 放在前面。实际排布与 FSDP wrapping 会改变预取峰值。
  • 反向不把“前一层 grad”当作从 CPU 搬回的梯度：它是额外完整梯度 / reduce 缓冲。参数 all-gather、梯度 reduce 均为设备间通信，与 H2D / D2H 分开。
  • 常驻权重、全量梯度 shard 及未 swap 状态计入所有阶段；临时 gather / reduce 视为独立缓冲。当前单位的激活与已保存激活按生命周期累加；swap 的激活在前向 D2H 完成后释放，在反向恢复。此处不建模 storage 复用或 allocator 碎片细节。
  • 明细未覆盖的 kernel workspace、EP 通信暂存、梯度累积的额外转换、优化器实现缓冲等，用“其他 HBM 预留”补充。默认 2 GiB 只是占位，需用实测校准。
  • 重计算按逐项比例估算容量，另保留边界输入；额外计算耗时尚未估算，MFU 使用基础模型 FLOPs / 实测时间。FP32 logits 按完整 seq_length × micro_batch_size × vocab_size 保存；实际融合 loss 可能减少这一项。KDA 内核内部 state / 中间张量若未在明细中列出，也不自动补全。
配置字段说明

公式和配置栏使用相同字段名。MLA、CSA/HCA 与通用 MoE 使用模型配置字段名；latent_h、KDA 的 head_dim / conv_size 沿用表格字段。各 attention 层数是本页结构计数字段；CSA/HCA 的两类压缩比例对应官方 compress_ratios 列表。

配置字段含义当前值

seq_length 是实际训练序列长度；micro_batch_size 是每 rank 单个 micro batch 的样本数；global_batch_size 是手动填写的每 step 全局样本数，用于 FLOPs / MFU。每卡等效 micro batch 数 = global_batch_size / (world_size × micro_batch_size)，用于激活搬运量；为正整数时即为梯度累积次数。moe_token_imbalance_factor 和 kda_core_flops_per_token 是本页的建模输入。

有效配置会保存到当前浏览器，并与“带宽与通信”页双向联动。使用“导出配置与结果”另存方案；浏览器禁用存储时跨页同步不可用。
