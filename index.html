所有激活项再展开模块单独调整；百分比按钮不自动开启 Swap

激活是每个 rank 的本地 micro batch，不除以 world size。保留表中保存张量的口径；Full attention scores（M13）与 latent up（M26）按原表汇总排除。非 2.8T 方案使用其模型维度，并统一套用 2.8T 公式。

FLOPs 与 MFU

MFU = 训练 FLOPs / (实测 step 秒数 × world_size × 每卡峰值 FLOPS)
训练 FLOPs ≈ 前向 FLOPs × 训练倍数
global_batch_size = world_size × micro_batch_size × gradient_accumulation_steps

调度、分片与生命周期

  • 共享专家、router、latent down/up 属于非路由专家参数，按 world_size 分片；仅 routed experts 按 EP 再 EP-FSDP 分片。无 tied embedding，所有专家均分配状态，top-K 只影响激活与计算。
  • 默认每个 micro batch 顺序执行完整前向和反向；梯度累积不叠加多份完整激活。MLA / KDA 按层数均匀穿插，Dense 放在前面。实际排布与 FSDP wrapping 会改变预取峰值。
  • 反向不把“前一层 grad”当作从 CPU 搬回的梯度：它是额外完整梯度 / reduce 缓冲。参数 all-gather、梯度 reduce 均为设备间通信，与 H2D / D2H 分开。
  • 常驻权重、全量梯度 shard 及未 swap 状态计入所有阶段；临时 gather / reduce 视为独立缓冲。当前单位的激活与已保存激活按生命周期累加；swap 的激活在前向 D2H 完成后释放，在反向恢复。此处不建模 storage 复用或 allocator 碎片细节。
  • 表格未覆盖的 kernel workspace、EP 通信暂存、梯度累积的额外转换、优化器实现缓冲等，用“其他 HBM 预留”补充。默认 2 GiB 只是占位，需用实测校准。
  • 模型不包含重计算。FP32 logits 按完整 seq_length × micro_batch_size × vocab_size 保存，与表格一致；实际融合 loss 可能减少这一项。KDA 内核内部 state / 中间张量若未在表中列出，也不自动补全。

相对原表的明确修正

  • I32 已包含 /EP，不能将 I55 再直接 /W 当作全局参数分片。全局参数从各子项重建；pre/post norm 按总层数计；final norm 跟随 hidden size。
  • 原 J60 使用 D28=8（Muon），本页统一按 Adam FP32 master + m + v，共 12 bytes/参数。梯度为另列的 2 或 4 bytes。
  • 激活沿用 2.8T 的 P53 汇总：包含 embedding 输入；原 M57 比 P53 少一项 M2。shared expert 数从硬编码 2 改为模型字段，Dense 激活乘实际 Dense 层数。
  • MFU 修正 lm head 的 D18→D19，补充 MLA gate、routed gate/up 少计的一路、shared down、router 与 KDA conv。KDA core FLOPs 需填实测实现对应值；未填时显示计算覆盖不完整。
  • 其他 sheet 仅导入维度。部分方案 MLA + KDA 与总层数不一致，选择时将 MLA 设为“总层数 − KDA”，并提示原值；若 KDA 已超过总层数，则按原 MLA:KDA 比例缩放到总层数。这个默认校准需按实际模型确认，可自行编辑。历史 sheet 的旧版激活公式没有与 2.8T 混用。
配置字段说明

公式和配置栏使用相同字段名。MLA / 通用 MoE 字段采用 DeepSeek 配置命名；latent_h、head_dim、conv_size 沿用你的表格字段。num_mla_layers、num_kda_layers、num_moe_layers 是本页的结构计数字段。

配置字段含义当前值

seq_length 是实际训练序列长度；micro_batch_size 是每 rank 单个 micro batch 的样本数；global_batch_size 包含 world_size 和梯度累积次数。moe_token_imbalance_factor 和 kda_core_flops_per_token 是本页的建模输入。
